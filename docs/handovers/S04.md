**S04 COMPLETE** on 28 October 2026, within its analysis-only scope. The core
now produces local CPU speech/uncertainty evidence for every participant and
physical PCM channel, with pinned model/runtime/licences, bounded stateful
decoding/inference and validated local caches. Known generated normal/soft/very
soft speech and brief acknowledgements remain protected in the labelled

and their tails remain intact. VAD alone does not establish laughter protection
or real-interview content acceptance. S05 has not been implemented.

## Changes and reasoning

- `interview_auto_editor/speech.py`: local CPU ONNX adapter; continuous full-WAV
  per-channel FFmpeg streams; bounded two-block queue; 512-sample model windows,
  64-sample context and `[2,1,128]` recurrent state carried across IO boundaries.
  EOF padding affects inference only, never source media. Exact absolute sample
  conversions and protection clamp to the measured source end.
- Speech scores >=0.50 emit speech. Intermediate scores >=0.15 or finite signal
  peaks >=0.0001 emit uncertainty for review. No minimum duration drops short
  responses. Same-kind evidence within 100 ms coalesces; default 120 ms onset
  and 200 ms tail padding are conservative development settings. Negative VAD
  never certifies silence. No reaction classifier or planner is hidden here.
- Every PCM channel is inferred separately; source semantic labels and physical
  channel evidence remain explicit. Shared microphones remain inseparable.
  Temporary resampling never changes the originals' rate, quality or layout.
- Each source cache binds content/grid/origin/labels/channels, settings,
  algorithm/source-module hash, model, pinned runtime/NumPy, Python/platform,
  decoder version/executable hash and resampler options. Paths, IO chunk size
  and future pacing targets do not change inference identity. Hits still verify
  model/runtime, source fingerprint, strict cache schema/event bounds and counts.
  Corrupt entries fail visibly. Exclusive atomic publication preserves completed
  entries and prevents partial cache files; cancellation kills/reaps decoding.
- The strict v1 analysis preserves all original sources/reviews and mirrors
  intake diagnostics into canonical reviews. The enclosing result retains the
  complete intake, tail/sequence measurements and original correlation anchors.
  Origins are never certified or shifted by speech evidence; null offsets stay
  null. The original exact-only tail plan refusal remains unchanged.
- `tools/s04_analyze.py`: offline, exclusive-new-report/private-contract command,
  complete-review exit 2, failure exit 1 and cancellation exit 130. It never
  returns a ready-to-edit success. Public-facing summaries neutralize supplied
  participant identifiers, while private contracts/cache retain fingerprints.
- `tools/s04_prepare_model.py`: explicit, bounded network setup with immutable
  URL/size/SHA verification, atomic creation and no overwrite. Analysis contains
  no download path or fallback detector. ONNX Runtime telemetry is disabled.
- `requirements-s04-win-py312.lock`, `third_party/`, `THIRD_PARTY_NOTICES.md`:
  exact model/runtime inventory, wheel hashes and licence/third-party texts.
  Source tooling version advances to 0.4.0. No binaries/models/wheels/voices are
  committed. Existing project licence and repository instructions are unchanged.
- `tools/test_s04_speech.py`, local-only TTS/build helpers and
  [S04_SPEECH_EVIDENCE.json](../fixtures/S04_SPEECH_EVIDENCE.json): focused
  development and boundary/recovery evidence. README, compatibility and
  [S04_SPEECH.md](../project/S04_SPEECH.md) explain actual use and limits.

### Failures and corrections retained

1. The first generated-speech assertion labelled an entire two-sentence span,
   including a genuine digital-silence gap. It failed because that silence was
   not wholly protected. Construction labels were corrected to independent
   speech regions; all annotated speech is now fully protected. Labels were
   not adjusted using VAD predictions.
2. The first full private run rejected finite temporary PCM peaks above 1.0.
   Sinc resampling of valid PCM can overshoot full scale. The check now rejects
   non-finite samples while passing finite overshoot through without clipping,
   gain changes or source repair. A focused regression proves sample values are
   unchanged. No incomplete cache was written by that failed run.
3. Dependency notice collection initially used a nonexistent upstream
   FlatBuffers `LICENSE.txt` URL (HTTP 404). The actual pinned release's
   `LICENSE` was retrieved and retained; runtime package pins were unaffected.

## Remaining limitations and blockers

No essential S04 blocker remains. No user action is required for this checkpoint.
Real speech/reaction labels, held-out examples, human listening and full G04
acceptance remain unproved. A fixed -80 dBFS signal safeguard can miss lower
signals and overprotect noise; VAD scores are not calibrated probabilities of
safety. Very soft speech in this fixture already demonstrates VAD-only misses.
S05 must retain uncertainty while evaluating reactions and bleed/correlation.

Audio buffers are bounded, while event metadata grows with activity and the
strict 8 MiB contract limit fails visibly for oversized records. Decoder limits
are explicit; slow/unsupported inputs can be refused. RF64/non-PCM WAV, broader
runtime/platform support, two-hour stress and clean-install packaging are not
closed. Private alignment/tail export remains refused by v1 exact coverage;
fixing this requires an explicit tested future policy, not silent repair.
