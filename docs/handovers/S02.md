## Changes and reasoning

- `tools/s02_kdenlive_adapter.py`: bounded reader/exact-build adapter and a
  small experimental proof CLI. It requires explicit participant mapping,
  simple zero-origin unedited entries and equal clip-grid coverage. It supports
  variable participant counts, ignores empty default tracks, excludes linked
  audio of the same MP4 and rejects unsupported/unsafe timing structures before
  writing. Outputs are exclusive new files.
- All tracks receive the same retained intervals. MP4 bin/timeline chains have
  audio disabled; video track playlists hide audio. Full originals stay in the
  bin; no media is rewritten. Groups/guides remain inside the adapter. Keeping
  this proof under `tools/` avoids inventing S03's canonical contracts early.
- `tools/s02_validate_render.py`: timeline and rendered A/V/gain measurements,
  separating the native sequence extent difference from matching timeline
  semantics. It measures an existing GUI render, not GUI provenance.
- `tools/test_s02_adapter.py`: 11 focused tests for shared timing, recovery,
  stream exclusion, no overwrite, explicit opt-in, invalid structures, native
  entry gain, genuine round trip, linked audio and counts 1/3/6/8 with spaces/
  Unicode. Mutated parser inputs are explicitly hand-authored, not GUI captures.
- New `s02-*` public fixtures: adapter-generated project, actual native-saved
  sanitized project, actual GUI render, render measurements and provenance.
  Existing S01 projects/media/reports were preserved.
- [S02_EXPORT_PROOF.md](../fixtures/S02_EXPORT_PROOF.md) records observations,
  commands, gain decision and recovery. README/COMPATIBILITY describe this proof.

**Gain decision:** native **per-entry Volume keyframes**, represented by
`mlt_service=volume`, `kdenlive_id=volume`, on the playlist entry. This was observed
by adding Volume in the actual GUI. Its 400 ms ramps/−60 dB plateau are editable
and measured. **No derived PCM fallback is needed for this S02 experiment.**
Sample/subframe envelopes and real listening/noise edges remain unproved; S08
must revisit fallback if needed. No gain-only PCM was generated.
