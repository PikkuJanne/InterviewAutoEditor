## Changes and reasoning

- `interview_auto_editor/turns.py` validates strict PlanningResult and exactly
  recomputes S06 before adding structure. Confident single-source speech joins
  across gaps up to 0.6 s; runs at least 0.6 s supply turns. Brief responses get
  backchannel cues. Shared microphones remain inseparable; reaction, uncertainty
  and ambiguous records remain cues. This describes source groups, not inferred
  human identity or accepted real-interview speaker accuracy.
- Substantial different-source turns propose retained-gap midpoint cuts. Shared
  pause seams are mandatory. A raw-event sweep records simultaneous source
  activity without inventing overlap across joined silence. Substantial overlap
  proposes outward frame-rounded bounds. Optional cuts stay at least 0.5 s from
  other cuts/seams/output ends; cues survive suppressed cuts. These are conservative
  structural settings, not calibrated pace preferences.
- `interview_auto_editor/adapters/export.py` integrates the S03 reader and S06
  plan. It checks exact adapter/FPS/domain, project/media fingerprints, explicit
  source/path bindings, unique names, full PCM counts and video PTS, then hashes
  sources again before atomic exclusive publication. XML is bounded. Stale,
  changed, unsupported or unreproducible input fails rather than silently repairs.
- Every map/edit-unit intersection gives identical source in/out and output
  position on every track. Native Normal groups contain one video and all N
  participant clips. Same-frame guides merge with exact source-clock explanations.
  Every MP4 chain disables embedded audio; linked/default tracks are omitted.
  Full original source producers/extents remain recoverable in the bin.
- `tools/s07_export.py` accepts existing strict mapping/result records with
  explicit experimental opt-in. It preserves reviews, emits safe counts and
  refuses overwrite/nonempty relocation mappings. Exit 0/2/1/130 means export,
  export needing review, refusal/failure or cancellation. S10's integrated
  run-folder API is still later work.
- `tools/s07_fixture.py`, `tools/test_s07_export.py` and
  `tests/fixtures/s07-turns-26.08.2/` add reproducible construction and actual
  application evidence with separate provenance. The before project is a
  hand-relinked S01 native file; after is adapter-generated. Native-roundtrip
  and ripple-extracted projects are sanitized actual saves. The MP4 is an actual
  GUI render of generated tones/test-picture media, containing no recorded people.
- `tools/s07_validate_render.py` remeasures native edits, shared A/V mapping,
  both overlap sources, duration and embedded-audio exclusion. It never creates
  GUI evidence. Guides/README/contracts/compatibility/state documents describe
  actual behavior and limits.

Canonical Analysis/EditPlan/S06 records stay v1. Original analysis, source-bound
approvals/decisions, protection, Keep/audible overrides and the one shared map
are unchanged. Structure never authorizes a removal. No gains, normalization,
denoising, source repair, per-track removal, camera retiming or decorative
transitions were added. Shared microphone labels are never split into voices.
