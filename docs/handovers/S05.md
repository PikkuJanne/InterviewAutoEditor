## Changes and reasoning

- `interview_auto_editor/reactions.py` implements one-thread local CPU YAMNet
  inference over each physical WAV channel and full source extent, including
  tails. Fixed 15,600-sample receptive fields overlap at 7,680-sample hops.
  Only analysis EOF windows are padded; source PCM is unchanged. Boundaries
  convert outward to exact source samples with 120/200 ms protection.
- Maximum laughter-family score >=0.10 adds `reaction`. Broad vocal/oral/crowd
  scores >=0.03 add uncertainty. No negative model result can remove S04 speech
  or uncertainty. Very quiet signal above a conservative empirical floor adds
  further uncertainty with score zero. No model score is calibrated safety
  confidence. Existing peak-based uncertainty remains intact.
- A bounded 32 ms RMS histogram estimates each channel's 10th-percentile floor.
  It is supporting evidence only: digital silence, cleaned tracks or continuous
  speech can bias it. Signal metadata is capped at 200,000 runs and fails visibly
  on overflow. Noise is substantially overprotected in the benchmark.
- Fusion appends events/reviews to S04, preserving its original objects and the
  exact intake. Raw cross-source activity intersections become potential overlap
  with score zero and uncertified-simultaneity reasons. Channels are unioned
  within a source first; shared microphones remain one inseparable group.
  Noise/bleed can cause these intersections. Correlation and loudness cannot
  overrule a quiet interruption; no individual attribution is inferred.
- Separate reaction caches bind source records, channel count, code/decoder
  identity, settings, model/runtime/Python/platform, CPU backend, window/hop/
  classes and floor method. IO chunk size, local paths and future pause settings
  are excluded. Hits still validate models, source bytes/grid, strict cache
  fields, event bounds/channel labels, decoded counts and floor block counts.
  Atomic exclusive publication and decoder cleanup reuse S04.
- `tools/s05_prepare_model.py` is explicit network setup with exact size/hash
  verification and no overwrite. Inference has no download/fallback path.
  `tools/s05_analyze.py` writes new neutral summaries and optional private v1
  contracts, always requiring review (exit 2; failure 1; cancellation 130).
- `tools/s05_benchmark.py` reads an explicit local development manifest. It
  separates positive clip detection from full interval retention and refuses
  `held_out` manifests. It never turns a category hit into a G04 pass.
- `tools/test_s05_reactions.py` adds 17 focused tests. The S05 guide, public
  aggregate evidence, dependency locks/notices, README and compatibility record
  describe actual behavior and limits. Original instructions, licence, S01-S04
  evidence, strict v1 contracts, speech path and exporter are preserved.

## Remaining limitations and blockers

The essential blocker is **independent human-confirmed sample-bound private
development labels**, on agreed representative examples covering laughter,
chuckles, yes/mm-hm, soft speech, uncertain sounds and genuine simultaneous talk,
including VAD misses. Existing local excerpts have only position-selection
metadata. A request for any existing labels was sent during the work; none were
available in the inspected repository/local index. The short pack makes the
required review concrete. It does not guarantee those three cues contain every
category and cannot silently become a representative agreed corpus.

After labels are supplied, validate/correct them independently of predictions,
evaluate complete protected intervals, and require zero annotated content loss.
Keep held-out labels/audio out of tuning and keep S05 active until this exit gate
passes. The execution protocol explicitly requires stopping blocked at missing
essential evidence; model guesses and high clip recall cannot replace it.

Expected limits: subthreshold events can still be missed; generic/quantized model
domain mismatch, noise overprotection and uncalibrated scores remain. Potential
overlap is not speaker identity or confirmed overlap, especially with uncertified
origins/shared microphones. Audio buffering is bounded; metadata/strict contract
size caps can refuse large inputs. Wider languages/accents, held-out listening,
full-interview acceptance, two-hour stress, broader runtime/platforms, release
packaging and native-library redistribution audit remain open.
