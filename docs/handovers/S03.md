## Changes and reasoning

- `interview_auto_editor/adapters/kdenlive.py`: independent read-only reader for
  the observed 26.08.2 structure. Bounded UTF-8 XML; no DTD/entities, duplicate
  IDs/properties, unresolved references, unsupported nesting, active processing,
  proxies, source/container/track offsets or unsafe edited timelines. All bin
  media references resolve. Known native clip/sequence extent differences are
  explicit. Fractional millisecond times require unique frame-grid recovery.
  This does not broaden S02 exporter or GUI support.
- `probe.py`: full decoded-frame PTS cadence audit and separate metadata timing,
  exact sample counts/rates/channels/widths, RIFF physical/chunk integrity,
  source fingerprints, local argument-array subprocesses with time/output bounds
  and fixed private-safe error codes. Nominal/average FPS is not accepted as a
  VFR certificate. Decoder errors and incomplete probes fail closed.
- `intake.py`: typed versioned mapping with unique explicit IDs/names and exact
  path matching; no filename-order inference. Explicit relocations and local
  spaces/Unicode work. Duplicate physical files, stale/extra/missing mappings,
  remote URLs and ambiguous paths fail. UNC requires explicit untested opt-in.
  Source clip ends, sequence ends and measured source ends remain separate.
- `offsets.py`: bounded reference-mix correlation records lag, score, window and
  uncertainty without suggesting/applying correction. Positive lag means later
  participant audio. Silence, repeated peaks, insufficient temporal coverage
  and changing lags cannot certify alignment. Three or more reliable windows
  spanning half the source are necessary even for a zero-lag diagnostic; cleaned
  mix correlation is still not an automatic shared-origin certificate.
- `timing.py`: exact rational frame/sample conversion, outward protection and
  inward removal rounding, one ordered shared map with full leading/trailing
  handles, exact absolute output positions and duration conservation.
- `contracts.py`: frozen typed v1 records and strict JSON codec for headers,
  fingerprints/versions/settings, source origins/offset status, per-source sample
  events/protection/channel labels, shot candidates, reviews, gains, overrides
  and aligned units. Unknown versions/fields, duplicate JSON keys, floats,
  invalid references/bounds and protected-content cuts are refused. Unverified
  offsets serialize as null. No implicit migrations exist.
- `tools/s03_inspect.py`: exclusive-new-report setup command, neutral report IDs,
  no output paths/names/source hashes, optional explicit diagnostic windows and
  clear failure/review exit statuses. It never exports a project or changes
  media. `test_s03_intake.py` / `test_s03_timing.py` add 22 tests.
- [S03_CONTRACTS.md](../project/S03_CONTRACTS.md), README, compatibility and the
  existing contract document explain usage, field/version rules, timing and
  limitations. The original S02 adapter, original fixtures, S01 real timing
  record, previous handovers, AGENTS and license are unchanged.

**Tail decision:** v1 permits only `exact_coverage` plans. Any nonzero measured
source-end difference is a review issue; a shortage of at least one project frame
is a truncation error. No tolerance silently drops samples. Plans cannot approve
unequal ends, unverified/nonzero origins or offsets. Future explicit tail
policies require a tested contract extension; S03 does not invent padding,
freezes or source repair. Non-destructive per-source analysis may proceed while
propagating these review states. Gain/event types establish interfaces, not S04
inference, S06 planning or S08 cleanup.
