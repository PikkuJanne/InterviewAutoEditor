## Changes and reasoning

- [`application.py`](../../interview_auto_editor/application.py) is the shared
  callable service. It invokes the existing policy modules; CLI/UI does not own
  timing rules. Fresh inspection and source hashes bind explicit saved analysis,
  requests and mapping. S09 refinement runs before S08 cleanup; a stale base-bound
  cleanup request refuses. No implicit approval rebinding or origin acceptance.
- Strict v1 manifests record service/input identity, command, stage, attempt,
  state and artifact hashes. Private inputs bind sources, project, requests,
  mappings, tools/models, implementation modules, runtime/platform and settings.
  Reports retain original diagnostics, exact source/output/null review locations,
  reasons, picture markers, cleanup and restoration instructions.
- An exclusive sibling `.NAME.incomplete` holds recoverable artifacts. An OS
  advisory lock prevents concurrent writers and releases on process death;
  its marker remains. All artifacts are new/exclusive, bounded to 8 MiB. Resume
  requires identical inputs/settings/code/paths and verifies every recorded
  artifact. Deterministic orphan outputs are adopted only after reproduction.
  Orphan summaries are revalidated, allowing valid changed cache-hit counters
  only. The first completed summary is retained; new runs record their own hits.
- Export is reproduced/revalidated into private scratch at the same directory
  depth, preserving final relative references. Only a fully validated bundle is
  renamed atomically to a **new** final directory. Existing empty targets also
  refuse. Windows/NTFS is tested; Linux renameat2 exists but is untested, and
  unsupported atomic-publication platforms fail closed. Atomic visibility does
  not promise power-loss durability.
- [`cancellation.py`](../../interview_auto_editor/cancellation.py) supplies a
  cooperative context. Probe/hash loops and per-frame peak audits check it;
  existing speech/reaction decoders already poll/reap. Ctrl-C and a local cancel
  flag stop before publication. Completed caches and staged evidence survive.
  Pure planning checks at stage boundaries. No serializer/gain/timing policy
  changed in the adapter, contracts, planner, turns, cleanup or picture modules.
- [`cli.py`](../../interview_auto_editor/cli.py) and the module entry point expose
  seven verified commands. Fixed console stages/errors omit user paths/hashes/
  content. Complete results return review exit **2**, refusal **1**, cancellation
  **130**. Compatibility probing is structural and explicitly does not certify
  the installed binary, GUI editability or future versions.
- [S10 guide](../project/S10_CLI.md), README and compatibility records document
  verified commands, approvals, private data, regeneration, recovery and limits.
  [Synthetic package](../../tests/fixtures/s10-cli-26.08.2/README.md) separates CLI
  construction from actual native saves/render. Full machine-specific run
  manifests remain ignored/local; they were not sanitized into fake executable
  reproduction records.

No source repair, shifting/stretching, padding/truncation, normalization/denoising,
